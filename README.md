# pi-tui-minimal

Quiet live-then-collapse rendering for the [pi](https://github.com/badlogic/pi-mono) coding agent. Load the extension and the style is on: no extra command, no toggle.

## Demo

[![asciicast: a pi session rendered by pi-tui-minimal](https://picui.ogmua.cn/s1/2026/10/10/6aca004975123.webp)](https://asciinema.org/a/1mvGYZl61op4tcGI)

## Install

It is a pi package on npm, so the install is one command:

```bash
pi install npm:pi-tui-minimal
```
